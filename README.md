# UiPath-Coders

This organization hosts UiPath automation projects built by the TAM (Technical Account Management) team, organized by vertical: Healthcare (hls), Pharma, Payer, and Health Tech. Each repository represents a focused automation or AI use case aligned to a customer vertical.

## Getting started

New contributors should refer to the `CONTRIBUTING.md` file in each repository for branching strategy, commit conventions, and UiPath Studio Git workflow guidelines.
